# pet privacy policy

pet runs entirely inside Claude Code on your computer. It does not collect, send or share any data with its author or anyone else, and it makes no network requests.

## What it reads

- **When Claude starts and finishes a turn**, so the pet can wake up while Claude works and sleep while it is idle. It does not read your prompts, Claude's replies or your files.
- **The `/pet` commands you type.**

## What it keeps

Two preferences, saved by Claude Code between sessions: which pet you chose (cat, dog or otter) and the band layout (`wrap` or `shrink`). For the current session only, it also keeps the pet's current activity and whether it is shown or hidden.

## What it sends

Nothing. pet has no servers, no analytics and no third parties, and it does not read credentials, run commands or touch any files.
